# C++ Developer Roadmap

This roadmap is designed to transform you from a beginner who knows syntax into a developer who can build real tools, read large codebases, and work confidently on Linux.

Most beginner paths teach only syntax:

```cpp
Variables
Loops
Functions
Classes
Pointers
```

This stops short of building software. This roadmap goes further by combining fundamentals, projects, Linux, Git, and real engineering skills.

---

## Goal

Become capable of:

* Building CLI tools and developer utilities
* Creating file managers and terminal applications
* Implementing Git-like version control systems
* Writing networking applications and chat servers
* Building databases and parsers
* Developing game engine components
* Reading and maintaining large codebases
* Using modern C++ professionally
* Using Git professionally
* Working in Linux confidently

---

## Phase 1 — C++ Fundamentals (2–4 weeks)

Learn:

* Variables and data types
* Input and output
* Operators and expressions
* Conditions and branching
* Loops
* Functions
* Arrays and strings

Projects:

* Calculator CLI
* Unit converter
* Student grade system

---

## Phase 2 — Developer Thinking (2 weeks)

Learn:

* Problem solving
* Algorithmic thinking
* Decomposition
* Pseudocode

Projects:

* Number guessing game
* Tic Tac Toe
* ATM simulator
* Library management system

---

## Phase 3 — Core C++ (4 weeks)

Learn:

* References and pointers
* Dynamic memory
* Structs and classes
* Constructors and destructors
* Object-oriented design

Projects:

* Contact book
* Inventory system

---

## Phase 4 — STL

Learn:

* vector

* set
* stack

## Phase 5 — File Systems

Learn:

* Reading and writing text files

## Phase 6 — Linux Developer Skills

Learn:

* Bash basics
